# Product: dark/light theme

## Problem
Users work in varying lighting conditions. Some prefer dark interfaces at night or in low-light environments. The current app is light-only, causing eye strain and visual discomfort for users who prefer dark mode.

## Announcement — the blog post before the feature
CommonCal now supports dark mode. Toggle between light and dark themes from the header. Your preference is saved automatically and persists across sessions. The app respects your system preference on first visit, then honors your manual override.

## Screens
- Header theme toggle button (light/dark icon switcher in `app-header__actions`)
- No new screens — toggle lives in existing authenticated shell header
